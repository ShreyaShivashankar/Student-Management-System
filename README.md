# Student Management System

A Java-based web application for managing student information.

## Technologies Used

* Java
* JSP
* Servlets
* HTML
* CSS
* MySQL
* Apache Tomcat

## Features

* Student Registration
* Student Login
* Student Dashboard
* View Student Profile
* Update Student Details
* Delete Student
* Forgot Password
* Logout

## Project Structure

The project uses Java Servlets and DAO classes for the backend, JSP and CSS for the frontend, and MySQL for database management.

## How to Run

1. Install Java and Eclipse.
2. Configure Apache Tomcat.
3. Configure MySQL.
4. Create the required database and tables.
5. Configure the database connection.
6. Run the project on Apache Tomcat.
